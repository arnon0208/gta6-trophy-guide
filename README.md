An offline guide and tracker for all 55 GTA VI PS5 trophies — a checklist that saves in the browser, a platinum roadmap in four stages, missable flags, and a cited guide for every trophy. All 55 trophies are offline and single-player; the whole list is earned in one playthrough in roughly 200–250 hours.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. The app is plain static files under app/ and works with the network off.
